# Quiz App – PROJ531 (Groupe 4)

Application Python permettant de créer et de passer des quiz.

## Fonctionnalités prévues
- Création de compte et connexion (mots de passe hachés)
- Historique des scores par utilisateur
- Création de quiz par un administrateur (manuelle ou depuis un fichier texte)
- Affichage du score final et des bonnes réponses
